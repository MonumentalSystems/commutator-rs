# Security policy

## Supported versions

Until the first stable release, security fixes target the latest release and
the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not open a public issue for a vulnerability that could affect downstream
experiments or distributed runtimes.

These crates provide scientific-computing primitives and protocol-neutral
types. They have not been independently audited for cryptographic use and must
not be treated as cryptographic implementations.
